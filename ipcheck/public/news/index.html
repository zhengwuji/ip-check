🤖 Claude / Anthropic

Claude 实时服务状态怎么查？
看官方状态页与本站「服务状态」页的聚合结果，先排除官方故障再排查本地线路。
 家宽、机房、原生 IP 有什么区别？
家宽信任度最高；机房 IP 风控更敏感；"原生"指归属地与注册地一致。
 时区与语言不一致会有影响吗？
出口地与浏览器环境差异是常见风控信号，尽量保持环境与出口一致。
 WebRTC 泄露对 AI 账号意味着什么？
STUN 看到的地址与出口不同说明 UDP 没走代理，建议开启 TUN 模式。
 DNS 泄露为什么也要查？
明文 DNS 会暴露访问的域名，可被用于推断位置，唯一子域名检测可验证加密情况。
 出口 IP 频繁变化有影响吗？
频繁跨国家/运营商切换会推高风控评分，本地的出口历史记录可帮你回顾轨迹。

💬 ChatGPT / Codex

ChatGPT / Codex 实时服务状态怎么查？
OpenAI 官方状态页实时汇总 ChatGPT 与 API 可用性，本站服务状态页会自动聚合。
 API 返回 401 说明什么？
未带密钥的请求返回 401 属于预期，它恰好证明网络与 API 边缘完全可达。
 Codex / API 用户与网页用户的差异
API 主要看出口 IP 与密钥绑定；网页版综合 IP、设备、指纹与行为，保持出口稳定最重要。
 出口 IP 频繁变化有影响吗？
频繁切换出口会显著推高风控评分，用本页底部的本地历史回顾变化轨迹。

🌐 IP 与网络

人机流量与场景评估是什么？
机房网段机器流量占比高、家宽以人类流量为主；场景分数是基于运营商类型的本地估算。
 RPKI / BGP 路由拓扑有什么用？
RPKI 验证路由来源合法性；上游拓扑可以看你的机房挂在哪些骨干网之下。
 DNS 泄露是什么？为什么你应该在意？
明文解析会把你访问的域名暴露给本地网络，唯一子域名检测能捕获真实解析路径。
 STUN 和 UDP 是什么？
WebRTC 通过 STUN 探测你的公网地址，可用于判断 UDP 流量是否被正确接管。
 Turnstile 人机验证为什么重要？
Cloudflare 风控的直观信号：非交互模式能否无感通过，反映当前 IP 的信誉状况。
 WHOIS 和 RDAP 有什么区别？
RDAP 是新一代注册数据协议，结构化 JSON、数据更规范；本站双通道互为备份。
