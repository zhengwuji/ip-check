📖 拓展阅读

Torrent 地址检测能查出什么？
最直接的答案是：你的 BT 客户端连出去时用的公网 IP。把它与浏览器出口对照，就能判断代理/VPN 是否真的接管了 BT 流量。同时它也是一面镜子——Tracker 能看到你，那么同一 swarm 里的其他 peer 与版权方同样能看到。
为什么挂了代理，BT 还是暴露真实 IP？
常见原因是代理只接管了浏览器的 HTTP/HTTPS 流量，而 BT 客户端默认直连（系统代理对它通常无效）。此外 DHT、PEX、本地发现等去中心化渠道根本不经过 Tracker，普通 HTTP 代理也拦不住它们。
怎么让 BT 走代理？
两条路：一是在 BT 客户端里手动配置代理（qBittorrent：设置→连接→代理服务器，并勾选「使用代理进行与 peer 的通信」；Transmission：编辑→偏好设置→网络→代理）；二是让代理客户端开启 TUN/虚拟网卡模式，接管整机 UDP 与 TCP 流量。配置后回到本页重测即可验证。
这个检测的原理和局限
原理：本页为你生成一个随机 info_hash，Magnet 链接里唯一的 Tracker 是本站地址。客户端添加链接后会按 BitTorrent 标准协议向它发起 HTTP announce，Tracker 记录请求来源并回显。局限：它只覆盖「向本站 Tracker announce」这一条路径；若你的客户端无法访问本站域名，或只走 DHT，这里就不会有数据。
隐私说明
info_hash 是浏览器随机生成、仅存于本次会话的标识，不含任何账号信息；结果页只有持有同一 info_hash 的人（也就是你这个页面）能查到；服务端记录会在 2 小时无活动后自动清除。
