什么是 IP 信息卡片？

    
IP 信息卡片是一张可以嵌到任何网页里的动态 SVG 图片。访客打开页面的那一刻，服务器实时识别他们自己的出口 IP，并渲染出 IP 地址、国家/城市、ASN 归属与网络类型，还可以标注纯净度评分。

    
它不是一张静态截图——把生成的 Markdown / HTML / BBCode 代码贴到博客、论坛签名或 GitHub README 之后，每一位看到的访客都会渲染出各自的 IP。同一张卡片服务所有人，无需登录，永久免费。
