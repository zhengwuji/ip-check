Cloudflare 节点检测能看出什么

全球有相当大比例的网站都架在 Cloudflare 前面。你打开这类网站时，请求并不会直达网站服务器，而是先落到 Cloudflare 离你网络最近的边缘数据中心（内部称 colo），再由它回源。命中哪个节点，直接影响打开速度、视频是否卡顿，也影响部分服务把你识别为哪个地区的用户。本页向 Cloudflare 的 cdn-cgi/trace 接口发一次请求，把返回的节点代码、出口 IP、WARP 状态与协议版本翻译成可读的结论。

风险指数怎么算

Cloudflare 企业版 Bot Management 的机器人分数并不对外公开，本页给出的风险指数是本站的等效评估：以出口 IP 在公开黑名单中的记录为基础，叠加公开代理、住宅代理、企业代理、VPN、Tor、机房 IP、滥用记录七类高置信信号，并结合 WARP 等连接特征综合计算。数值越小越好，60 以上通常意味着访问 Cloudflare 站点时更容易遇到人机验证或拦截。更细的评分依据可以打开 IP 评分页 查看。

人机验证结果怎么看

  • 无感自动通过：Turnstile 不需要任何操作就完成校验，说明 Cloudflare 对当前浏览器与网络信任度高，是最理想的结果。
  • 需要点击验证：托管模式弹出「确认你是人类」勾选框，点一下即可通过。环境整体正常，但存在少量可疑特征。
  • 无法通过：即使点击也校验失败，通常是浏览器指纹异常、自动化特征明显或 IP 信誉较差，访问很多站点会反复遇到验证码。

三种常见的异常场景

  • 人在亚洲，节点在美国：免费版 Cloudflare 站点从中国大陆或部分东南亚线路出发时，常被调度到 LAX、SJC 这类远端节点，延迟从几十毫秒涨到两百毫秒以上。对比表里「免费版」与「企业版」两行命中不同节点，就是这种情况。
  • 出口 IP 与首页不一致：说明你的代理或分流规则对 Cloudflare 流量做了单独处理。可以配合首页的分流测试核对规则是否按预期生效。
  • WARP 显示已开启：出口 IP 会变成 Cloudflare 自己的地址（AS13335）。这类 IP 在 ChatGPT、Claude 等服务的风控里评分偏低，注册和登录更容易被拦。

常见问题

什么是 Cloudflare 边缘节点（colo）？
Cloudflare 把服务器部署在全球各地的数据中心里，每个位置用当地机场的三字母代码标识，比如 HKG 是香港、NRT 是东京、LAX 是洛杉矶。你访问任何接入 Cloudflare 的网站，请求都会先落到离你网络最近的那个节点，再由它回源到网站服务器。本页读取 cdn-cgi/trace 返回的节点代码，并翻译成城市和国家。
为什么免费版和企业版网站命中的 Cloudflare 节点不一样？
Cloudflare 会按套餐使用不同的调度策略。免费与 Pro 套餐的流量在某些地区（尤其是从中国大陆和部分东南亚线路出发时）可能被调度到更远的节点；企业级网络与 Cloudflare 自家服务（如 1.1.1.1、speed.cloudflare.com）则更倾向命中就近节点。本页把同一条线路下不同等级站点的命中结果并排展示，有没有差异一比就知道。
Cloudflare 出口 IP 和普通出口 IP 有什么区别？
普通出口 IP 是你直连网站时对方看到的地址；Cloudflare 出口 IP 是你访问接入 Cloudflare 的网站时，Cloudflare 边缘记录到的来源地址。当代理或分流规则对 Cloudflare 流量做了特殊处理时，两者会不一样。配合首页的分流测试与本页的出口 IP，可以确认规则是否真的生效。
WARP 是什么？warp=on 和 warp=plus 是什么意思？
WARP 是 Cloudflare 提供的加密隧道服务，开启后流量会先进入 Cloudflare 网络再发往目标网站。trace 结果里 warp=off 表示未使用；warp=on 表示免费版 WARP；warp=plus 表示 WARP+ 付费版。开启后出口 IP 会变成 Cloudflare 的地址（AS13335），不少网站对这类地址执行更严格的风控。
延迟多少算正常？
命中同城或同区域节点时，浏览器到 Cloudflare 边缘的往返通常在 5 到 60 毫秒；跨海到美国西海岸大约 120 到 200 毫秒；超过 300 毫秒多半是绕路或被调度到了远端。本页延迟是浏览器发起完整请求的耗时，会略高于纯网络往返，更适合用来横向对比不同等级网络。
HTTP/3 和 TLS 1.3 显示未启用怎么办？
HTTP/3 基于 QUIC（UDP 443），浏览器通常要在第二次访问同一站点后才切换过去；如果始终停在 HTTP/2，可能是代理或防火墙没有放行 UDP 443。TLS 1.3 是当前主流版本，现代浏览器默认支持；如果显示 TLS 1.2，往往说明链路上有代理在做降级或审计。
Turnstile 无感通过和需要点击有什么区别？
Turnstile 是 Cloudflare 的人机验证组件。非交互模式全程在后台完成；托管模式由 Cloudflare 根据浏览器指纹、网络信誉与行为特征决定是否弹出勾选框。无感通过代表 Cloudflare 高度信任当前环境；需要点击说明存在少量可疑特征；点击后仍失败则风险较高，日常上网会频繁遇到验证。本页取得的 token 还会提交到本站服务器做 siteverify 二次校验，显示 PASS 才算完整走通流程。
这个页面会记录我的 IP 吗？
不会。所有检测均由你的浏览器直接向 Cloudflare 的接口发起，节点历史只写入你自己浏览器的本地存储，清除按钮一键可删；本站服务器不保存任何查询记录。
