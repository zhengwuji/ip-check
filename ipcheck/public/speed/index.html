测速结果比宽带套餐低很多，正常吗？
常见原因：Wi-Fi 信号差或连接的是 2.4G 频段、代理/VPN 链路限速、运营商忙时拥塞、以及测速节点不在同一区域。测速只反映「你到 Cloudflare 边缘」的带宽，访问其它网站时路径不同，速度也会不同。
为什么用 Cloudflare 做测速节点？
Cloudflare 在全球 300 多个城市部署了边缘节点，绝大多数用户都能连到非常近的节点，且支持大文件下行与上行回传，测出的延迟更接近真实链路质量。它并非在每个国家都有节点，结果仅供参考。
延迟和抖动分别是什么？
延迟是数据包往返一次的耗时，影响网页打开、游戏、语音的即时响应；抖动是多次延迟之间的波动程度，抖动越大，视频通话和实时游戏越容易卡顿。一般延迟 < 50ms、抖动 < 5ms 属于优秀。
挂代理时测速，测的是谁的带宽？
测的是「你 → 代理 → Cloudflare」整条链路的带宽。想验证代理节点速度就开着代理测，想验证宽带本身请关掉代理再测，两次结果对比还能看出代理的开销。
