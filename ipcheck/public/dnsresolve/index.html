各家结果不一致，说明被劫持了吗？
不一定。大型网站用智能 CDN，不同位置的解析器会拿到不同的就近节点 IP，这属于正常调度；被污染的典型特征是：所有主流服务商都返回真实答案，唯独某个结果雷同于一个完全无关的 IP（常见于被墙域名），或返回了大量保留地址。
DoH 与传统 UDP 查询有什么区别？
传统 DNS 是明文 UDP，中间设备能看到并篡改查询；DoH 把查询装进 HTTPS（443 端口），链路上只能看到「你在和某个解析器通信」，看不到查了什么。本页直查/代查全部走 DoH。
为什么有的服务商查询很慢或失败？
部分服务商对某些地区或数据中心的查询做了限速/拒绝（例如把公共云出口识别为滥用来源），另外跨域策略要求本机直查的服务商必须显式开放 CORS。失败行不代表服务商不可用，只代表这条查询路径不通。
TTL 是什么？为什么每次查到的不一样？
TTL 是记录允许被缓存的秒数。解析器缓存未过期时会把缓存答案直接返回（TTL 递减），所以同一域名在不同服务商、不同时间查到的 TTL 与 IP 都可能不同。TTL 很短（如 60s）通常意味着该域名做了快速切换或故障转移。
