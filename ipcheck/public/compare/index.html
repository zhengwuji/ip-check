对比模式怎么用

  • 换节点前后对比：先在 A 填当前节点 IP，切换代理后再在 B 填新节点 IP，看纯净度与风险信号变化。
  • 原生 IP vs 中转 IP：把疑似原生的 IP 和机场中转 IP 各测一次，类型、ASN 归属、机房标签的差异会非常直观。
  • 分流规则验证：分别测「直连出口」与「代理出口」，确认规则把流量分到了预期线路。

对比仅读取两个 IP 的静态画像，不做实时互通性测试；想测连通质量请用「全球 Ping」与「网络连通」页。
