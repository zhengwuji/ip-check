ChatGPT / Codex 实时服务状态怎么查？
OpenAI 官方状态页实时汇总 ChatGPT 与 API 的可用性，本站「服务状态」页面会自动聚合。出现大面积异常时先看状态页，再排查本地代理线路。
家宽、机房、原生 IP 有什么区别？
家宽（ISP）IP 信任度最高；机房（Hosting）IP 被批量使用、风控更敏感；"原生"指 IP 归属地与注册地一致。本页信任评分基于这三类计算，并叠加代理特征检测。
时区与语言不一致会有影响吗？
出口在美国但浏览器是 UTC+8 + 中文，是风控的常见信号之一，会推高整体风险评分，但单独出现通常不触发封禁。尽量让浏览器环境与出口一致更稳妥。
API 返回 401 说明什么？
本页对 api.openai.com 发起未带密钥的请求，官方返回 401 属于预期结果——它证明网络与 API 边缘完全可达。若显示"不可达"，说明当前出口根本连不上 OpenAI。
WebRTC 泄露对 AI 账号意味着什么？
如果 STUN 看到的地址与出口不同，说明 UDP 没走代理，真实宽带 IP 可能已暴露。部分风控会比对"注册地"与"常用出口"，建议保持 UDP 也走代理（TUN 模式）。
DNS 泄露为什么也要查？
明文 DNS 会把访问的域名暴露给本地网络，并可能被用于推断位置。「DNS泄露」页面的唯一子域名检测可以验证你的解析是否已加密。
Codex / API 用户与网页用户的差异
Codex 和 API 调用主要看出口 IP 与密钥绑定情况，浏览器指纹影响较小；网页版则会综合 IP、设备、指纹、行为。两者共用同一出口时，保持出口稳定最重要。
出口 IP 频繁变化有影响吗？
频繁跨国家/跨运营商切换出口会显著推高风控评分。本页底部的「出口 IP 历史记录」（仅存本地）可以帮你回顾最近的出口变化轨迹。
